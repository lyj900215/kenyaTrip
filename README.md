# kenyaTrip

中肯双向旅游 AI 平台：为中国游客提供肯尼亚旅游（入肯），为肯尼亚居民提供中国旅游与商务考察（入华）。核心能力是 **AI 路线推荐、AI 行程规划、一键式机酒车预订**，采用轻资产、技术主导模式。
